# Reporte-NPS

Reportes de Calidad Claro Ecuador · A365, con el diseño del PPT corporativo (banda roja de título, paleta rojo / azul marino / gris).

| Archivo | Qué es |
|---|---|
| `NPS CLARO ECUADOR.html` | Dashboard de encuestas post-llamada: NPS, FCR, EPA, CS y OC por mes, día, supervisor y asesor. Botón **Presentación ▸** para abrir el informe de ventas. |
| `PRESENTACIÓN CLARO.html` | Informe de Calidad Ventas en 14 láminas + Gracias. Carga la base `.xlsx` de Qualtrics, se puede presentar a pantalla completa y descargar como PowerPoint (una lámina por sección). Botón **◂ Encuestas NPS** para volver. |

Para que los botones entre reportes funcionen, los dos archivos deben estar en la misma carpeta y conservar sus nombres.
